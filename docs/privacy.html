Privacy

Last updated September 21, 2026

Whisk is a clipboard manager. Everything it remembers is what you copy, and it keeps it on your Mac. There is no account, no analytics, no tracking, no advertising, and no third-party software development kit inside the app. The developer receives no data from Whisk.

What Whisk stores

Whisk records the content you copy — text, links, images, colors, and the names and locations of files — together with the time of the copy and the name of the application it came from, plus the pins and settings you choose. This history is a local database:

  • ~/Library/Application Support/Whisk for the build downloaded from GitHub or installed with Homebrew;
  • the app's own sandbox container for the build from the Mac App Store.

You control it entirely: delete any item, clear the unpinned ones, set how long items are kept and how many, exclude applications whose copies must never be recorded, or pause capture. Content that password managers and other apps mark as confidential is never recorded. Deleting the database folder, or uninstalling Whisk, removes everything.

What leaves your Mac

Two optional features make network requests. Nothing else does.

  • Link previews. When a copied link is shown, Whisk asks the linked website for its title and image, through Apple's LinkPresentation framework. That website sees the request as any browser visit: your network address and the link. Turn this off under Settings → Privacy; no request is made afterwards, and the card shows the bare address.
  • Update check — GitHub and Homebrew build only. At launch, Whisk asks api.github.com for the latest release number and compares it with its own; nothing about you is sent. Turn it off under Settings → General. The Mac App Store build never checks: the App Store handles its updates.

Permissions

  • Accessibility is optional and used for one thing: sending the paste keystroke to the application you were working in when you pick a card. Without it, Whisk still copies the card to the clipboard for you to paste yourself.
  • Open at login is optional and only registers Whisk as a login item.
  • Files. Whisk never browses your disk. It sees the files you copy, and writes a file only where you choose to save one.

Sharing and third parties

Whisk shares nothing with anyone. The only third parties involved are the websites you copy links from, when link previews are on, and GitHub, when the update check is on.

Children

Whisk is a general-purpose utility, not directed at children, and collects no personal information from anyone.

Changes and contact

Changes to this page are recorded in the project's history on GitHub. Questions go through the support page; security concerns follow the security policy. Whisk is open source under the GPL-3.0-or-later: every claim on this page can be checked in the source code.
