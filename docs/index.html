01 THE TERMINAL WAY

One command. You’re in.

brew install --cask nathan-poncet/tap/whisk

Installs the prebuilt app straight into /Applications. Until Whisk ships notarized, clear Gatekeeper's quarantine once: xattr -d com.apple.quarantine /Applications/Whisk.app.

02 THE DRAG-AND-DROP WAY

Download. Drop. Done.

Download Whisk.dmg

Drag Whisk into Applications. The app is not notarized yet: on first launch, allow it in System Settings → Privacy & Security → Open Anyway.
