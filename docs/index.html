Whisk

Your clipboard, remembered.

A free, open-source clipboard manager for macOS. Everything you copy lands in a Liquid Glass panel — search it, filter it, pin it, stack it, drag it, paste it. All local, keyboard-first.

Everything a clipboard should have kept

📋

Full history, persisted

Every copy is captured and stored locally — text, links, colors, images and files. Keep it forever or auto-expire it; pins never die.

🔍

Search that understands

Type to filter instantly, by content or by the app it came from. Operators like app:safari and type:link combine with free text.

🥞

Paste stack

Queue several cards with ⇧⏎ — press again to unqueue, each card wears its rank — then pop them one by one anywhere with a global shortcut. Collect once, paste in order.

⌨️

Keyboard-first, layout-aware

Arrows, ⏎ to paste in place, ⌥⏎ for plain text, ⌘1…9 for direct hits, ⌘Y for a full preview. Every shortcut is remappable and follows your keyboard layout — Dvorak included.

✨

Rich previews

Links show their title and cover image, code is syntax-highlighted, colors render as swatches, files get QuickLook thumbnails. Cards carry the tint and icon of their source app.

📝

Rich text, your call

Formatting is captured and pasted back faithfully — and ⌥⏎ pastes as plain text when you'd rather drop it.

🖱️

Drag & drop

Grab any card and drop it straight into another application — text, links, colors, images and files all travel.

🔒

Private by design

History never leaves your Mac (SQLite on disk). Concealed content from password managers is never recorded, capture pauses from the menu bar, and you can exclude any app entirely.

🌍

English & français

The whole interface follows your system language — panel, settings and onboarding included.

Install

🍺 Homebrew

brew install --cask nathan-poncet/tap/whisk

Installs the prebuilt app straight into /Applications. Until Whisk ships notarized, clear Gatekeeper's quarantine once: xattr -d com.apple.quarantine /Applications/Whisk.app.

💿 DMG

Download Whisk.dmg

Unsigned build: on first launch, right-click → Open, or run xattr -cr /Applications/Whisk.app.

Open source, open kitchen

Whisk is GPL-3.0 and built with Clean Architecture in Swift — entities and use cases at the core, adapters at the edges, a dependency rule checked in CI. Issues and pull requests welcome.
