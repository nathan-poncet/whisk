Whisk

Your clipboard, remembered.

A free, open-source clipboard manager for macOS. Everything you copy lands in a Liquid Glass panel — search it, filter it, pin it, stack it, drag it, paste it. All local, keyboard-first.

Everything a clipboard should have kept

Real footage, no mock-ups. Pick a step, or let it play through.

  1. 🗂️

    Everything you copied, one panel

    Text, links, colors, images, files, code — each card wears the icon and tint of the app it came from, newest first.

    ⇧⌘V
  2. 🔍

    Search & filters that understand

    Type slack invoice and find the invoice you copied from Slack. app: and type: scope it tight; chips narrow by app or kind, and never build a dead end.

  3. 🎨

    You see what you paste

    Colors render as swatches, links show their title and cover, code arrives highlighted, files get thumbnails. Click a card and it lands right where you type.

    ⏎
  4. 🥞

    Paste stack

    Queue cards with ⇧⏎, then pop them one by one into any form with ⌥⌘V — collect once, paste in order, never alt-tab back.

    ⇧⏎then⌥⌘V
  5. 👁️

    Look first, then paste

    ⌘Y opens any card full size — the whole text, the full image, the file list. ⌘Y or Esc closes it.

    ⌘Y
  6. 🖱️

    Drag & drop

    Every card is draggable — an image into Mail, a file into Finder, text into a doc. The panel floats over your work, so the drop target is already on screen.

Hands stay on the keyboard

Arrows, ⏎ in place, ⌘1…9 direct hits, ⌘Y for a big preview. Every shortcut is remappable and follows your actual layout — Dvorak and AZERTY included.

🟩

Speaks fluent Vim

Flip one switch and the panel opens in normal mode — hjkl to move, gg and G to jump, p to paste, dd to delete, / to search. Every key rebindable.

hlggGpdd
Click here and type h l gg G p dd.
🔒

Private by design

Your history never leaves your Mac — no cloud, no account, no analytics. Password managers stay unrecorded, capture pauses in one click, and any app can be excluded for good.

📌

Keeps what matters, forgets the rest

Pin a card and it survives Clear, eviction and retention. Let the rest expire after 24 hours, 7 days or 30 days — or keep everything, forever, with an unlimited capacity.

Install

🍺 Homebrew

brew install --cask nathan-poncet/tap/whisk

Installs the prebuilt app straight into /Applications. Until Whisk ships notarized, clear Gatekeeper's quarantine once: xattr -d com.apple.quarantine /Applications/Whisk.app.

💿 DMG

Download Whisk.dmg

Unsigned build: on first launch, right-click → Open, or run xattr -cr /Applications/Whisk.app.

Open source, open kitchen

Whisk is GPL-3.0 and built with Clean Architecture in Swift — entities and use cases at the core, adapters at the edges, a dependency rule checked in CI. Issues and pull requests welcome.
